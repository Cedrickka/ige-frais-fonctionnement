# IGE · Gestion des frais de fonctionnement

Application WordPress de l'Inspection Générale de l'Enseignement (Ministère de l'Éducation Nationale et Nouvelle Citoyenneté, RDC).

- `theme/` : thème « IGE Frais de fonctionnement », conforme à la charte graphique du Gouvernement de la RDC.
- `extension/` : extension « IGE Frais de fonctionnement (métier) » : base de données, rôles, écrans, règles de gestion.

Chaque dossier a son propre README (installation, tests, fonctions).
